# 물리 마스터 에디터 스튜디오 (PicEditor)

웹 브라우저에서 바로 실행할 수 있는 물리 문제 및 도식/도면 편집기 웹 애플리케이션입니다.

## ✨ 주요 기능
- **선택 및 편집 모드**: 요소 선택, 이동, 크기 조절 및 회전
- **다양한 도구 지원**: 직선, 화살표, 도형, 텍스트 상자 등
- **반전 및 변환 기능**: 가로/세로 반전, 직선→화살표 변환
- **불러오기 / 저장**: 파일 불러오기 및 고해상도 PNG 다운로드 지원

## 🚀 실행 방법
별도의 설치 과정 없이 브라우저에서 바로 실행할 수 있습니다:
1. `index.html` (또는 `PicEditor.html`) 파일을 더블 클릭하여 크롬/웨일/엣지 등 최신 웹 브라우저로 엽니다.
2. 또는 GitHub Pages를 활성화하면 웹 링크(`https://<사용자이름>.github.io/<저장소이름>/`)로 접속하여 사용할 수 있습니다.
