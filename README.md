# 물리 마스터 에디터 스튜디오 (PicEditor)

웹 브라우저에서 바로 실행할 수 있는 물리 문제 및 도식/도면 벡터 그래픽 편집기 웹 애플리케이션입니다.  
성균관대 심층면접 모의 문항 등 물리 시험 도면 57종 전체에 대한 100% 완전 벡터화 라이브러리와 GitHub 클라우드 저장/갤러리 연동 기능을 탑재하고 있습니다.

## ✨ 주요 기능

1. **완전 벡터 객체 편집 (100% Pure SVG)**
   - 모든 도면 요소(`<line>`, `<path>`, `<circle>`, `<polygon>`, `<rect>`, `<text>`)가 개별적으로 선택 가능하며, 마우스 드래그로 이동, 크기 조절, 회전(45° 스냅), 반전 가능.
   - 비트맵(`<image>`) 의존성 없는 무결점 벡터 렌더링.

2. **인터랙티브 작도 도구**
   - **직선 및 화살표:** 일반 직선 및 단방향/양방향/중앙 화살표 작도 및 상호 변환.
   - **호(Arc):** 대칭형 베지에 곡선 기반 물리 각도/궤적 호 작도 (볼록 방향 반전 지원).

3. **텍스트 렌더링 & 배경 박스 인스펙터**
   - 텍스트 크기(`%`) 및 내용 실시간 편집.
   - 글자 크기에 맞춰 오차 없이 자동 밀착되는 3가지 배경 모드: `투명`, `박스 흰색`, `테두리 흰색`.

4. **GitHub 클라우드 연동 및 시각적 보관함 갤러리 (`github.js`)**
   - **[☁️ 깃허브에 저장]:** 작업 중인 캔버스 HTML 및 400px PNG 썸네일을 GitHub 저장소(`saved/`)에 원클릭 자동 커밋.
   - **[🖼️ 깃허브 보관함]:** 썸네일 그리드 카드로 구성된 갤러리 모달 제공, 실시간 검색 필터링 및 클릭 시 캔버스 원클릭 로드.
   - **[⚙️ 깃허브 설정]:** Personal Access Token (PAT) 및 대상 저장소 안전 저장.

5. **성균관대 물리 심층면접 모의 문항 57종 라이브러리 탑재**
   - 역학, 열역학, 전자기학, 파동/광학 등 전 영역 57개 도면 완벽 탑재.
   - 모든 일본어 표기를 표준 한국어 물리 용어로 전수 번역 완료.
